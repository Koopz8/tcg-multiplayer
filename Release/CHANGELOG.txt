CHANGELOG
=========

0.10.1
------
* Fixed the monitor mover messing up your resolution. It was forcing the
  target monitor's native res on every move (and Unity saves that, so it
  stuck), then placing the window 40px off the corner so the edges got cut
  off. Moving is just a move now.
* New "Match this monitor's resolution" button under Monitor in the panel,
  for anyone who already got bitten by the above. Panel also shows what res
  you're actually running at.
* Ride along no longer offers you a seat in a bus's card reader.

0.10.0
------
* Vehicles actually move for other players now. Before this a friend driving
  the golf cart looked like a body sliding down the road with the cart still
  parked. Works for anything that drives, including whatever gets added later.
* Ride along - walk up to something a friend is driving and press F7 to get
  in, F7 again to get out. Seats depend on size (2 in the cart, more in the
  bus). You get put back on your feet automatically if the driver leaves,
  the session ends, or anything goes wrong. F11 still gets you out of
  everything.
* Fixed a vehicle snapping back a frame after moving.

0.9.8
-----
* Nexus download is now a manual install - just the mod file. Install
  MelonLoader yourself, drop one folder in. Updating = replace one file.
  The one-click installer still exists for testers on discord, it's just not
  on the public page.
* Mouse stays inside the game window while the panel is open, so clicking
  the panel on a second monitor doesn't drop you out of the game. Turn off
  "Keep the cursor in the window" in the config if you'd rather not.
* Closing the panel gives the pointer straight back to the game.

0.9.7
-----
* Fixed the mouse pointer flickering with the panel open. The game re-locks
  the cursor ~40 times a second and the mod was unlocking it just as often.
  Now it stops the game grabbing it in the first place.

0.9.6
-----
* Game no longer looks frozen when you open the panel. 0.9.5 was disabling
  ALL game input while the panel was open, which also killed the game's own
  menus. Now it only holds your keys while you're actually typing in chat or
  the lobby ID box.
* F11 also releases the input lock.

0.9.5
-----
* Typing in chat could still walk your character. Two things underneath:
  the mod was looking for the game's input system in a way that doesn't
  work on this build (it's obfuscated), and it only tried once per panel
  open, before the input system was ready. Fixed both.

0.9.4
-----
* Input lock could give up permanently if the panel was opened before the
  game finished starting. It retries now and says so in the panel.
* Self-check was reporting "economy globals aren't readable" when it just
  hadn't looked yet.

0.9.3 - public beta
-------------------
* Session reports. Every time a session ends a text file goes into
  TcgMultiplayer_Reports next to the game (last 20 kept, Copy button in the
  panel). Has pings, versions, machine events, blocked payouts, whether your
  progression got restored. Nothing is uploaded, it's a file you choose to
  send. If you're testing, please send it with the MelonLoader log from both
  sides.
* Installer warns if BepInEx is in the same folder. Two loaders = the game
  starts with no mods and no hint why.

0.9.2 - closed beta
-------------------
* Self-check on F10. Checks the wire format, weird names with emoji, bad
  packets, machine ids, the wallet guard, the save backup, and that a full
  visit to someone's island gives your own stuff back - against your real
  save, takes a couple seconds. Copy result button. Says at the bottom what
  it does NOT test (Steam actually delivering packets between two PCs).
* A peer sending garbage packets can't flood the log anymore.

0.9.1
-----
* Cut the mod's frame cost. It was rebuilding its machine list constantly
  on busy machines (coin pushers), walking ~4500 state machines every couple
  seconds. You could feel it.
* Performance panel: fps, worst frame, and how many ms the mod itself is
  using. If the game stutters and that number is ~0, it's not this.
* Save backup no longer tries to copy the game's log file (always open,
  always failed).

0.9.0
-----
First build meant for the public.

* Your save gets copied aside the first time you host or join. Five kept,
  in TcgMultiplayer_SaveBackups next to the save. Button in the panel too.
* Visiting someone's island doesn't follow you home anymore. Your own
  unlocks are held aside while you're a guest and put back when you leave.
  This was the most dangerous thing in the mod, it's now the most tested.
* Refuses to join a host on a different mod version, and says which you
  each have.
* Different game build gets flagged in the panel, not just the log.
* Host leaving ends the session cleanly for everyone.
* Every per-frame part of the mod is isolated - a bug in one switches that
  feature off and tells you, instead of throwing 60 times a second.
* Panel no longer opens on startup. F9.
* Solo testing tools folded behind a toggle.
* On quit the session closes before the game saves, so a guest's own
  progression is restored first.

0.8.0
-----
* Steam achievements/stats/leaderboards blocked during a session. Spectating
  replays a friend's round on your machine, so their score could've posted
  under your name. Single player unaffected.
* Health panel that lists anything the mod expected to find and didn't.
* Game build fingerprinted and compared between players.

0.4.0  - per-player wallets
0.3.0  - machine ownership and spectating
