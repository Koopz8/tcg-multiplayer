CHANGELOG
=========

0.9.3 - public beta
-------------------
Added
  * A session report, written automatically every time a session ends, into a
    TcgMultiplayer_Reports folder next to the game. There's also a Copy button
    in the panel. Last 20 are kept.

    It records how long you played, whether you hosted or joined, how it ended,
    everyone's ping and mod version, machines and events, physics mismatches,
    payouts the wallet guard blocked, and whether your progression was put back
    properly. Nothing is sent anywhere - it's a file on your disk that you
    choose to send.

    If you're testing: please send this along with the MelonLoader log, from
    both sides of the session.

  * The installer now notices if BepInEx is installed in the same game folder
    and warns you. The other Coin Game mods use it, and two mod loaders in one
    folder usually means the game starts with no mods at all and no hint why.

0.9.2 - closed beta
-------------------
Added
  * A self-check, on F10 or the button in the panel. It verifies the wire
    format for every message type, that awkward names with accents and emoji
    survive, that malformed packets are rejected instead of crashing, that
    machine ids are stable and unique, that the wallet guard is armed, that
    the save backup really writes files - and that a full visit to someone
    else's island gives your own progression back afterwards, tested against
    your real save in a couple of seconds.

    There's a Copy result button so you can paste the outcome into a report.
    It says at the bottom what it does NOT test, which is Steam actually
    delivering packets between two machines. Only a real session tests that.

Changed
  * A peer sending malformed packets can no longer flood the log - after ten
    it says so once and goes quiet. They're almost always just on a different
    version.

0.9.1
-----
  * Cut what the mod costs per frame. It was rebuilding its machine list
    whenever the number of active state machines moved a little, and coin
    pushers move it constantly - so on a busy machine it was walking about
    4,500 of them twice, every two seconds. That's a hitch you can feel.
  * Added a performance panel: frame rate, worst frame in the last second,
    and exactly how many milliseconds the mod itself is using. If the game
    stutters and that number is near zero, it isn't this.
  * The save backup no longer tries to copy the game's own log file, which
    is always open and always failed.

0.9.0
-----
First build prepared for public release.

Added
  * Your save is copied aside the first time you host or join a session.
    Five copies are kept, in a TcgMultiplayer_SaveBackups folder next to the
    save itself. There's also a button in the panel to do it on demand.

  * Visiting someone else's island no longer follows you home. Your own
    unlocks are held aside while you're a guest and put back when you leave,
    and anything you unlocked yourself while visiting stays yours. This was
    the most dangerous thing about the mod and it is now the safest.

  * The mod refuses to join a host running a different version of it, and
    says which version each of you has. Two different versions could read
    each other's packets wrongly, and the symptoms would have looked like
    anything except the real cause.

  * A different build of the game is now flagged in the panel rather than
    only in a log file nobody opens.

  * If the host leaves, the session ends cleanly for everyone instead of
    Steam quietly handing the lobby to a guest who does not have the world.

  * Every part of the mod that runs each frame is isolated. A bug in one of
    them switches that feature off and says so in the panel, instead of
    throwing sixty times a second and taking your framerate with it. There's
    a button to try them again without restarting.

Changed
  * The panel no longer opens on startup. Press F9 when you want it.
  * The solo testing tools are folded away behind a toggle.
  * On quit, the session is closed before anything else, so a guest's own
    progression is restored before the game writes its save.


0.8.0
-----
  * Steam achievements, stats and leaderboards are blocked for the duration
    of a session. Spectating replays a friend's round on your machine, so
    without this their score could post under your name. Single player is
    completely unaffected.
  * A health panel that names anything the mod expected to find and didn't,
    rather than failing silently.
  * The game build is fingerprinted and compared between players.

0.7.0
